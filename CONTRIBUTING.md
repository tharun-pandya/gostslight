# Contributing

1. Fork, branch, keep changes focused.
2. Backend: `pip install -r requirements-dev.txt && cd backend && python -m pytest -q`.
3. Frontend: `cd frontend && npm ci && npm test && npm run build`.
4. Never commit recordings, vault data (`data/`), `.env`, or real family content. Sample data must be fictional and labelled DEMO DATA.
5. Safety rules are non-negotiable: no voice cloning, no impersonation of people, no hosted-AI calls on private data, every memory needs transcript evidence.
